Examples of Using .format()



1. Basic Formatting
name = "Alice"
age = 25
message = "My name is {} and I am {} years old.".format(name, age)
print(message)

Output:
My name is Alice and I am 25 years old.
2. Positional Arguments
You can specify the order of values using numbers inside the placeholders:
message = "I love {1} and {0}.".format("Python", "JavaScript")
print(message)

Output:
I love JavaScript and Python.
3. Keyword Arguments
You can use keywords instead of positional arguments:
message = "My favorite color is {color}.".format(color="blue")
print(message)

Output:
My favorite color is blue.
4. Mixing Positional and Keyword Arguments
message = "I like {0} and {language}.".format("coding", language="Python")
print(message)

Output:
I like coding and Python.
5. Formatting Numbers
Decimals:
pi = 3.14159
print("Pi is approximately {:.2f}".format(pi))

Output:
Pi is approximately 3.14


Padding and Alignment:
print("{:<10} is left-aligned".format("Hello"))   # Left-aligned
print("{:>10} is right-aligned".format("Hello"))  # Right-aligned
print("{:^10} is centered".format("Hello"))       # Centered

Output:
Hello      is left-aligned
     Hello is right-aligned
  Hello    is centered
6. Using Dictionaries with .format()
data = {"name": "Bob", "age": 30}
message = "Name: {name}, Age: {age}".format(**data)
print(message)
Output:
Name: Bob, Age: 30
7. Using Lists or Tuples
values = ["Alice", 28]
message = "Name: {}, Age: {}".format(*values)
print(message)
Output:
Name: Alice, Age: 28
