Basic Dictionary Operations:
Create a dictionary: my_dict = {"name": "Alice", "age": 25, "city": "New York"}

Access a value by key: my_dict["name"]

Add a new key-value pair: my_dict["country"] = "USA"

Update an existing value: my_dict["age"] = 26

Delete a key-value pair: del my_dict["city"]

Check if a key exists: "name" in my_dict

Get the length of the dictionary: len(my_dict)

Dictionary Methods:
my_dict.get(key, default)
Safely get the value of a key, returning default if the key does not exist.

my_dict.keys()
Returns a view of all keys in the dictionary.

my_dict.values()
Returns a view of all values in the dictionary.

my_dict.items()
Returns a view of all key-value pairs as tuples.

my_dict.pop(key, default)
Removes the key and returns its value, or returns default if the key does not exist.

my_dict.popitem()
Removes and returns the last inserted key-value pair as a tuple.

my_dict.clear()
Removes all items from the dictionary.

my_dict.update(another_dict)
Updates the dictionary with key-value pairs from another_dict.

Iterating Through Dictionaries:
Iterate over keys: for key in my_dict:

Iterate over values: for value in my_dict.values():

Iterate over key-value pairs: for key, value in my_dict.items():

Dictionary Comprehensions:
Create a dictionary from a range: {x: x**2 for x in range(5)}

Filter a dictionary: {k: v for k, v in my_dict.items() if v > 10}

Merging Dictionaries:
Using update(): dict1.update(dict2)

Using dictionary unpacking: {**dict1, **dict2}

Common Use Cases:
Count the frequency of elements in a list: frequency = {x: my_list.count(x) for x in my_list}

Swap keys and values: {v: k for k, v in my_dict.items()}

Sort dictionary by keys: sorted_dict = {k: my_dict[k] for k in sorted(my_dict)}

Sort dictionary by values: sorted_dict = dict(sorted(my_dict.items(), key=lambda item: item[1]))

Special Operations:
Set a default value for a key if it doesn’t exist: my_dict.setdefault("key", "default_value")

Create a dictionary with default values: new_dict = dict.fromkeys(["a", "b", "c"], 0)

Use defaultdict for automatic default values (requires collections): from collections import defaultdict; dd = defaultdict(int)

Use Counter to count elements (requires collections): from collections import Counter; count = Counter(my_list)

Nested Dictionaries:
Access nested values: my_dict["outer"]["inner"]

Add a nested dictionary: my_dict["new_key"] = {"inner_key": "value"}
